# 工作生活专属 APP

只供本人使用的工作生活管理工具，在本机浏览器运行，不上网、不登录、无手机版。

包含 9 个模块：首页总览、今日计划、自媒体、开发工作、咨询工作、健身计划、饮食计划、游戏娱乐、数据与设置。

## 如何启动

1. 双击 `启动.bat`
2. 浏览器会自动打开 `http://127.0.0.1:3344`

> 需要电脑已安装 Node.js（本机已安装）。启动后会出现一个最小化的小窗口，那是服务窗口，不要关掉它。

## 如何停止

- 双击 `停止.bat`，或
- 直接关闭那个最小化的服务窗口。

## 数据保存在哪里

- 主数据文件：`app/data/data.json`
- 自动备份文件：`app/data/data.backup.json`（每次保存前自动保留最近一份）

所有操作实时自动保存；刷新、关闭、重启电脑都不会丢。若 `data.json` 损坏，启动时会自动用备份恢复。

## 备份建议

在「数据与设置」页可以：

- 查看数据文件完整路径
- 一键导出备份文件
- 一键从备份文件导入恢复

建议定期导出一份备份到别的文件夹。

## 目录结构

```
启动.bat          双击启动
停止.bat          双击停止
README.md         本说明
PRD.md            产品需求文档
DEVELOPMENT_PLAN.md 开发计划
app/server.js     本地服务（Node.js，零依赖）
app/index.html    页面入口
app/css/style.css 样式
app/js/           前端逻辑（数据层 + 9 个页面）
app/data/         数据文件（自动生成）
test/             自动化测试（node --test）
```

## 运行测试

在项目根目录执行：

```
node --test
```
